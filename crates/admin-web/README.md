# `crates/admin-web`

## 目录

```text
admin-web/
├── client/
├── session/
├── ui/
├── mock/
├── page-auth/
├── page-overview/
├── page-account/
├── page-admin/
└── page-users/
```

## 要实现

- `client` 调用管理 API 和管理鉴权 token。
- `session` 保存登录态。
- `ui` 提供公共管理组件。
- `mock` 提供页面开发数据。
- `page-auth` 提供登录和注册。
- `page-overview` 展示总览、模型和排行。
- `page-account` 管理密钥、用量和奖励。
- `page-admin` 管理渠道、分组、兑换、订阅和系统。
- `page-users` 管理用户。
