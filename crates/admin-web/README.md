# `crates/admin-web`

## 功能 crate

- `client/` — 管理 API 请求、响应信封和 token 注入。
- `session/` — 登录、刷新、登出和全局会话。
- `ui/` — 管理端共享 Dioxus 组件。
- `mock/` — 页面开发的管理数据。
- `page-auth/` — 认证页面。
- `page-overview/` — 总览、模型和排行榜。
- `page-account/` — 个人 Key、用量和奖励。
- `page-admin/` — 渠道、分组、兑换、订阅和系统。
- `page-users/` — 用户列表和用户管理。

## 单机 MVP 页面

- `page-auth/` — 登录和当前用户。
- `page-admin/` — 渠道、Token、模型映射和探活。
- `page-overview/` — 请求量、成本、成功率和渠道状态。
- `page-account/` — 用户 API Key 和使用量。
