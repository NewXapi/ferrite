# `crates/tavern-web`

## 功能 crate

- `client/` — 调用 `/tavern/*` 与消费 SSE。
- `state/` — 角色、聊天、消息和生成状态。
- `ui/` — 消息、输入、对话框和加载组件。
- `page-characters/` — 角色列表、新建和编辑。
- `page-chat/` — 聊天、生成、swipe、编辑和历史。
- `page-settings/` — 连接、模型、密钥和采样设置。

## MVP 页面

- `page-characters/` — 创建角色并选中。
- `page-chat/` — 发送消息、显示流式回复、保存和恢复聊天。
- `page-settings/` — 保存模型和采样设置。
